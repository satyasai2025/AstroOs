## 2026-07-20 — Task #11 complete: Worker Pools & Batch Scaling (Local-First)

- **Core** (`apps/api/services/worker_pool.py`): three named pools (`cpu`/`io`/`ai`), each a `ThreadPoolExecutor` fed by a dedicated dispatcher thread draining a priority heap (`JobPriority.INTERACTIVE` before `BULK`, FIFO within a priority — verified by test with a single-worker pool and an explicit ordering assertion). Retry with exponential backoff (`WORKER_MAX_RETRIES`/`WORKER_RETRY_BASE_DELAY_SECONDS`), dead-letter after exhaustion (never silently dropped). Local autoscaler thread grows/shrinks each pool within `[MIN,MAX]` from `Settings` based on queue depth vs in-flight count — no K8s HPA. Cooperative cancellation (`job.cancel_requested` + `JobCancelled`) plus immediate cancel for still-queued jobs. Prometheus metrics: `worker_jobs_submitted_total`, `worker_jobs_completed_total`, `worker_queue_depth`, `worker_pool_size`, `worker_job_duration_seconds` — feeds the Phase II.2 observability stack directly.
- **Batch job API**: `POST /api/v1/batch/chart-reports` (up to 5000 subjects, runs on the `io` pool, BULK priority) → `GET /api/v1/batch/{id}` (poll, with per-subject progress), `GET /api/v1/batch/{id}/download` (zip), `DELETE /api/v1/batch/{id}` (cancel). `apps/api/services/batch_report_service.py` reuses `HoroscopeEngine`/`ReportEngine`/`ReportTemplateEngine` unchanged — no duplicated business logic. Per-subject failures are captured in the zip's `MANIFEST.txt`, not fatal to the batch.
- **Job monitoring** (Celery-Flower alternative, local): `GET /api/v1/jobs` (JSON, filterable), `GET /api/v1/jobs/pools` (pool sizes/queue depth), `GET /api/v1/jobs/monitor/html` (self-refreshing HTML dashboard, zero JS dependencies).
- **Config**: `WORKER_{CPU,IO,AI}_{MIN,MAX}`, `WORKER_AUTOSCALE_INTERVAL_SECONDS`, `WORKER_MAX_RETRIES`, `WORKER_RETRY_BASE_DELAY_SECONDS`, `WORKER_JOB_TTL_SECONDS`, `BATCH_OUTPUT_DIR` added to `apps/api/config.py`. Wired into `apps/api/main.py` lifespan (single process-wide `WorkerPoolManager`, same singleton pattern as `EphemerisWrapper`) and shutdown.
- **Testing**: `tests/unit/test_worker_pool.py` (11 tests: completion, retry-then-succeed, retry-exhaustion→dead-letter, priority ordering, queued-cancel, running-job cooperative cancel, progress tracking, autoscale-grows-under-backlog, manager routing, TTL eviction, dict shape) and `tests/unit/test_batch_report_service.py` (9 tests) — 20/20 passing.
