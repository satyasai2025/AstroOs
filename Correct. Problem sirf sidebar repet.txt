# AstroOS — Professional Visual Design & UX Audit

Perform a **full visual and UX audit of the existing AstroOS frontend before making any UI changes**.

The current dark theme is functional but the overall interface does not yet look sufficiently professional, cohesive, refined, or premium for a serious astrology research and analysis platform.

The problem is NOT simply "make it darker" or "add better colors".

The objective is to determine why the interface currently feels visually weak and define a professional design system before implementation.

# 4. Audit Visual Hierarchy

For every major screen determine:

### Primary visual focus

What should the user notice first?

### Secondary focus

What should they notice next?

### Tertiary information

What should remain visually quiet?

The current UI should not give equal visual weight to:

```text
Page title
Navigation
Tabs
Cards
Metrics
Actions
Secondary metadata
```

Create a clear hierarchy.

Define a restrained surface system.

Example structure:

```text

Workspace Background

Primary Surface
        ↓
Secondary Surface
        ↓

        ↓
Interactive Surface
```

Each layer should have a clear visual distinction.

Do not solve hierarchy by adding more colors.

Prefer subtle changes in:

* luminance
* border
* elevation
* spacing
