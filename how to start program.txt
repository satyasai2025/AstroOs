## Everyday routine

**First time each session (or after a reboot):**
```bash
cd "C:\Users\rkmau\Downloads\ReplitplusClaude\AstroOS"
```
```bash
pm2 status
```
Check if `astroos-api` and `astroos-web` are already `online`. If pm2 says "no processes" (like right now, since I killed the daemon), start them:
```bash
pm2 start ecosystem.config.js
```

**Then just use it:**
- App: `http://localhost:3000`
- Admin panel: `http://localhost:3000/admin-login`

**That's genuinely it, most days.** Once you've run `pm2 start` and `pm2 save` once (from your own terminal, per the last step I asked you to do), the Windows startup registration means pm2 auto-resurrects both processes when you log in — you won't even need to run the start command again unless something actually crashed.

**If something looks broken:**
```bash
pm2 status
```
(all `online`, restart count not climbing?)
```bash
pm2 logs
```
(see what's actually erroring)
```bash
pm2 restart all
```
(nuke-and-restart if unsure)

**When you're done for the day:** nothing required — leave it running, or `pm2 stop all` if you want the ports/resources back.

The only manual step left on your end right now is the one from before: run `pm2 start ecosystem.config.js` then `pm2 save` yourself, once, from your own terminal (not through me) — that's what makes the startup registration point at a clean process list instead of the leaked one I deleted.

Complete Workflow Plan: Start & Restart AstroOS Next.js with PM2
📋 Step 1: Fresh Machine Startup
1.1 Open Terminal (Windows)
Press Win + R → Type cmd or powershell → Enter
Or use Git Bash if you prefer Unix-style commands
1.2 Navigate to Project Root

cd /c/Users/rkmau/Downloads/ReplitplusClaude/AstroOS
📦 Step 2: Environment Setup
2.1 Verify Node.js Installation

node --version
# Should show v18.x or higher
npm --version
2.2 Install Dependencies (if needed)

npm install
⚙️ Step 3: PM2 Configuration
3.1 Replace ecosystem.config.js at Project Root

// /ecosystem.config.js
module.exports = {
  apps: [{
    name: 'astroos-web',
    script: 'npm',
    args: 'run dev',
    cwd: './apps/web',
    instances: 1,
    exec_mode: 'fork',
    env: {
      NODE_ENV: 'development',
    },
    env_production: {
      NODE_ENV: 'production',
    },
    max_memory_restart: '512M',
    error_file: './logs/web-error.log',
    out_file: './logs/web-out.log',
    log_date_format: 'YYYY-MM-DD HH:mm:ss',
  }]
}
▶️ Step 4: Start the Development Server
4.1 Create Logs Directory (if missing)

mkdir logs
4.2 Kill Any Existing Process on Port 3000

taskkill /PID $(netstat -ano | findstr :3000 | head -n1 | awk '{print $5}') /F 2>/dev/null || echo "No process on port 3000"
4.3 Clean PM2 (Ensure Fresh Start)

pm2 delete all
4.4 Start AstroOS via PM2

pm2 start ecosystem.config.js --env development
4.5 Save PM2 Processes

pm2 save
🔄 Step 5: Monitor & Restart Workflow
5.1 View Running Apps

pm2 list
5.2 Watch Live Logs

pm2 logs astroos-web
5.3 Restart on Code Changes (Only if Hot Reload Fails)

pm2 restart astroos-web
5.4 Check Server Health

curl http://localhost:3000/charts/compare
🛠️ Step 6: Troubleshooting Commands
6.1 Kill All Node Processes if PM2 Crashes

taskkill /IM node.exe /F
6.2 Clear Cache (if Stale Data Persists)

# Stop server
pm2 stop astroos-web

# Delete Next.js cache
del /Q apps/web\.next\* 2>nul || rm -rf apps/web/.next

# Restart
pm2 start ecosystem.config.js --env development
6.3 Reset PM2 (Nuclear Option)

pm2 kill          # Kill daemon
pm2 unstartup     # Remove startup scripts
pm2 delete all    # Clean apps
pm2 save          # Save empty state
